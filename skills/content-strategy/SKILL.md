# Content strategy

## Use

Apply this when the task matches the description. Keep the output decision-useful and mark unknowns.

## Method

1. Name the audience and the promise.
2. Find credible proof.
3. Choose one channel and one test.
4. Measure qualified behavior, not vanity metrics.

**Focus:** Content strategy.

## Verification

- Test has a pre-registered metric and sample.
- Result includes uncertainty and next step.
- State clearly what was not verified.

## Boundaries

- This is a checklist, not proof of correctness.
- No fabricated sources, data, or test results.
- If the task falls outside the method, say so and stop.
