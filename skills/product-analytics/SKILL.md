# Product analytics

## Use

Apply this when the task matches the description. Keep the output decision-useful and mark unknowns.

## Method

1. Name the user, problem, and current alternative.
2. List options with tradeoffs.
3. Test the smallest risky assumption.
4. Measure behavior and guardrails.

**Focus:** Product analytics.

## Verification

- Prototype or test produced behavioral evidence.
- Guardrail metrics did not regress.
- State clearly what was not verified.

## Boundaries

- This is a checklist, not proof of correctness.
- No fabricated sources, data, or test results.
- If the task falls outside the method, say so and stop.
