# Grant writing

## Use

Apply this when the task matches the description. Keep the output decision-useful and mark unknowns.

## Method

1. State the question and prior work.
2. Separate source, observation, and inference.
3. Record uncertainty and method limits.
4. Make the result reproducible.

**Focus:** Grant writing.

## Verification

- Every citation resolves and supports the claim.
- Commands/data are sufficient to rerun.
- State clearly what was not verified.

## Boundaries

- This is a checklist, not proof of correctness.
- No fabricated sources, data, or test results.
- If the task falls outside the method, say so and stop.
