# Stakeholder map

## Use

Apply this when the task matches the description. Keep the output decision-useful and mark unknowns.

## Method

1. Name the owner and decision.
2. Expose risks, dependencies, and non-goals.
3. Set cadence and written outcomes.
4. Record the decision and review date.

**Focus:** Stakeholder map.

## Verification

- Owner and decision date are recorded.
- Risks have triggers and mitigations.
- State clearly what was not verified.

## Boundaries

- This is a checklist, not proof of correctness.
- No fabricated sources, data, or test results.
- If the task falls outside the method, say so and stop.
